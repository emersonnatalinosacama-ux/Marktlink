Versão profissional

Atribuição segura de vendas

Na versão com servidor, cada campanha recebe um ID único. O servidor regista vendedor → campanha → clique → produto → pedido → venda e calcula automaticamente a taxa de plataforma de US$2 por venda confirmada.

1. Clique

O link /r/<campanha> é registado no servidor antes de encaminhar o comprador.

2. Pedido

O checkout aceita apenas o produto associado à campanha, evitando atribuição arbitrária.

3. Pagamento

O saldo só é actualizado após confirmação de pagamento por webhook do provedor.

4. Taxa

US$2 é debitado no servidor e não pode ser alterado pelo navegador.
